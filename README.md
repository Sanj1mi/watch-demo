## Команда	Что делает
[make up] -	собрать и поднять весь стек в Docker (http://localhost)
[make down]	остановить всё
[make logs] s=backend	логи в реальном времени (без s= показывает все сервисы)
[make ps]	статус контейнеров
[make restart] s=backend	перезапустить один сервис
[make rebuild]	пересобрать без кэша и поднять
[make sh s=frontend]	shell внутри контейнера (по умолчанию backend)
[make psql]	консоль PostgreSQL

## Для разработки
Команда	Что делает
[make dev]	БД и бэк в Docker, плюс vite-сервер (http://localhost:5173)
[make dev-down]	остановить dev-стек
